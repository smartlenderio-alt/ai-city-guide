# AI City Guide

🤖 AI PERSONAL LOCAL GUIDE — LOVABLE BUILD PROMPT

Build a professional, production-quality AI-powered local travel and discovery application called “NeonGuide AI”.

The app should feel like a combination of:

An AI personal travel assistant

A smart local guide

A trip planner

A local business discovery platform

A real-time navigation assistant

A digital travel log

The overall experience should be premium, futuristic, intelligent, fast, mobile-first, and highly visual.

Use the concept and information architecture of modern travel-log/planner apps such as Wanderlog as inspiration, but DO NOT directly copy proprietary UI, branding, assets, or layouts. Create an original interface with a strong AI + cyberpunk + neon travel-tech identity.

and produce the best possible local experience.
